# Zerodha Clone – Trading Dashboard

A full-stack Zerodha-inspired trading platform clone built using React, Node.js, Express, and MongoDB. The project includes a public-facing frontend, an interactive trading dashboard, and a backend API for managing holdings, positions, and orders.

## Features
- Zerodha-inspired landing page
- Dashboard for holdings, positions, orders, and funds
- Watchlist and portfolio summary
- MongoDB integration with Mongoose
- REST API using Express
- Modular React components

## Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB
- Mongoose
- JavaScript
- HTML/CSS
